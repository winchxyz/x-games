Games

Post the link. On desktop the game opens inside the post; on a phone it opens full screen without leaving X.

How it works

01

A post is the console

The game is a web page. X loads it in a frame inside the post, so playing takes no install and no new tab.

02

One link per game

Anyone can post it. Every post of the link is a playable copy of the game.

03

What X allows today

Inline play on desktop web, in a square frame. In the mobile apps the same link opens full screen inside X.

Build one

Four lines in the page head. A square frame is the largest X will show; anything taller gets cropped and shrunk.

<meta name="twitter:card" content="player">
<meta name="twitter:player" content="https://your.site/game/">
<meta name="twitter:player:width" content="1080">
<meta name="twitter:player:height" content="1080">
<meta name="twitter:image" content="https://your.site/game/preview.png">
